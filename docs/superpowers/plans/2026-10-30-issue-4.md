# Age rule (issue #4) Implementation Plan

> **For agentic workers:** Build with `/build-ticket 4`. This is a single-task plan: the work stays uncommitted in the working tree for gate 2. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plain-code rule that decides whether a speech error the model heard is still normal for the child's age, so only age-inappropriate errors reach the therapist.

**Architecture:** One module, `speakup/age_norms.py`, holds a small table keyed by `(sound, error_type)`. Each row has the age in months at which the error starts to flag and the ASHA source URL. `should_flag` looks up the row and compares the age. No model code and no I/O.

**Tech Stack:** Python 3, standard library only (`dataclasses`, `unittest`).

**Spec:** GitHub issue #4 ("Age rule: drop errors that are normal for the child's age"). The vocabulary for `sound` and `error_type` comes from issue #3's proposed result fields: `target_sound` is `"r"`, `error_type` is `"gliding"`, `"distortion"`, or `None` when the sound is correct.

## Global Constraints

- Standard library only; the code runs on the SK-AM62B board.
- Never commit audio or child data. Tests use made-up ages only.
- The rule is plain code, not part of model training.
- Each table row carries its ASHA source URL next to it.
- An unknown error type raises; it never guesses.

## Decisions taken in this plan (gate 1)

1. **Gliding of r flags from 84 months (7;0).** ASHA's Selected Phonological Processes table gives gliding a likely elimination age of "6–7". The issue's *Decided* section says "A 6-year-old who glides is still normal", so 6;11 (83 months) must not flag. That answers the issue's first *Needs Lexi* question with 7;0. Source: https://www.asha.org/practice-portal/clinical-topics/articulation-and-phonology/selected-phonological-processes/
2. **Distorted r flags from 96 months (8;0). This is a proposal; Lexi has not answered it.** ASHA's articulation-and-phonology page links Crowe & McLeod (2020), Table 2. At the 90% criterion, /ɹ/ has a mean of 66.58 months, SD 18.62, range 30–96 months. The plan uses the top of that range: no study in the table still expects r errors after 96 months. For a screener that tries not to over-refer, that is the safe end. The alternative is the mean (67 months), which would flag a distorted r earlier than gliding. Source: https://www.asha.org/siteassets/practice-portal/speech-sound-disorders-articulation-and-phonology/consonant-age-of-acquisition.pdf
3. **"After which it gets flagged" means `age_months >= flag_from_months`.** A child exactly 84 months old who glides is flagged.
4. **The table is a Python module, not JSON.** A frozen dataclass row keeps the URL next to the number and needs no file loading on the board.
5. **Unknown inputs raise `ValueError`.** This covers an unknown error type, an unknown sound with an error, and a wrong case such as `"Gliding"`. A correct sound (`error_type is None`) returns `False` before the lookup, whatever the sound or age.
6. **Done-when item 4 (Lexi's yes "in the PR") is not a build step.** Under this protocol the work lands on main at accept and no PR is opened. Proposed: before accept, the owner shows Lexi the table in `speakup/age_norms.py` and Lexi writes her yes, or her numbers, as a comment on issue #4. If the owner wants a real PR instead, say so at gate 1.

## Review Focus

1. Age exactly at the cutoff (84, 96): flags. Pinned by the edge tests.
2. A correct sound with an unknown sound or a far-out age (`None, "s", 200`): returns `False`, does not raise. Pinned by `test_correct_sound_never_flags`.
3. Error type in the wrong case (`"Gliding"`): raises, not a silent `False`. Pinned by `test_unknown_error_type_raises`.
4. Known error type on a sound the table lacks (`"gliding", "s", 100`): raises. Pinned by `test_unknown_sound_raises`.
5. Every row has an ASHA URL. Pinned by `test_every_row_cites_asha`.

Not covered, by design: an age passed in years instead of months (for example `7`) silently returns `False`. The caller (#5 or #6) owns converting a birth date to months.

```python
import unittest

from speakup.age_norms import AGE_NORMS, should_flag


class ShouldFlagTest(unittest.TestCase):
    def test_gliding_edges(self):
        self.assertFalse(should_flag("gliding", "r", 83))
        self.assertTrue(should_flag("gliding", "r", 84))

    def test_distortion_edges(self):
        self.assertFalse(should_flag("distortion", "r", 95))
        self.assertTrue(should_flag("distortion", "r", 96))

    def test_correct_sound_never_flags(self):
        for age in (0, 83, 84, 96, 200):
            self.assertFalse(should_flag(None, "r", age))
        self.assertFalse(should_flag(None, "s", 200))

    def test_unknown_error_type_raises(self):
        for error_type in ("stopping", "Gliding", ""):
            with self.assertRaises(ValueError):
                should_flag(error_type, "r", 100)

    def test_unknown_sound_raises(self):
        with self.assertRaises(ValueError):
            should_flag("gliding", "s", 100)

    def test_every_row_cites_asha(self):
        for norm in AGE_NORMS.values():
            self.assertTrue(norm.source.startswith("https://www.asha.org/"))
```
