# Session summary (issue #7) Implementation Plan

> **For agentic workers:** Build with `/build-ticket 7`. This is a single-task plan: the work stays uncommitted in the working tree for gate 2. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At the end of a session, turn its results into a short plain-English summary for the therapist, where the code decides pass or refer and a swappable model function only puts the facts into words.

**Architecture:** One new module, `speakup/summary.py`. It reads a list of `Result` records (#3) and the child's age in months, works out which errors are flagged with `should_flag` (#4), and builds two things from that: the pass or refer line (plain code) and a prompt that lists the facts. `summarize` sends the prompt to a `generate` function passed in by the caller and puts the code's line above the model's text. #9 passes a llama.cpp function; tests pass a fake.

**Tech Stack:** Python 3, standard library only (`typing`, `unittest`).

**Spec:** GitHub issue #7 ("Session summary: the function and prompt, with a fake model"). Consumes `speakup/result.py` (#3, see `docs/result-format.md`) and `speakup/age_norms.py` (#4). Consumer: #9 (llama.cpp on the board and the end screen).

## Global Constraints

- Standard library only; the code runs on the SK-AM62B board.
- "The pass or refer line comes from the code, not the model. The model only puts the facts into words."
- "The model call is one function that can be swapped, so #9 can point it at llama.cpp on the board."
- No llama.cpp, no model download, no network in this ticket. Out of scope: "Free-form questions from the therapist. Any cloud model."
- Never commit audio or child data. Tests use made-up words and ages only. The prompt carries no name: `Result` has no name field, and nothing here adds one.
- It screens; it does not diagnose. The prompt tells the model so.

## Decisions taken in this plan (gate 1)

1. **Refer when any one word is flagged; pass when none is.** The ticket names no threshold, and there is no source for a number such as "2 of 5". One flagged word is enough to put the child in front of the SLP, who decides. If Lexi wants a threshold, it is one comparison to change.
2. **The pass or refer line is the first line of the summary, and the model's text follows.** The SLP reads the decision first, and a long or wrong model reply cannot push it out of sight. Exact copy:
   - `Pass: 0 of 5 words flagged for age 6;8.`
   - `Refer: 2 of 5 words flagged for age 7;6 (rabbit, mirror).`
   Age is shown as years;months, the way SLPs write it.
3. **Input is `Result` objects plus `age_months: int`, and the flags are computed inside.** "Results with the #4 flags" is read as: this module calls `should_flag` itself, so there is no second type that carries a flag. The caller (#5) runs `check(d)` on each dict from the model first.
4. **The model function is `Callable[[str], str]`: one prompt string in, text out, and it is a required argument.** #9 wraps the string in the model's chat template (llama.cpp does that for Instruct models). There is no default, so a fake can never stand in for the real model by accident. The fake lives in the test file only; the ticket asks for it in the tests.
5. **An empty session raises `ValueError`.** "Pass: 0 of 0 words" would tell the SLP a child passed a screen they never took.
6. **Every try counts as one word.** If a child says "rabbit" twice, both tries count and both show by name. No de-duplication.

## Review Focus

1. The model's text says "pass" when the code says refer: the first line is still the code's refer line, unchanged. Pinned by `test_code_line_comes_first_whatever_the_model_says`.
2. An empty session: raises `ValueError`, and the model is never called. Pinned by `test_empty_session_raises_before_the_model`.
3. An error with `heard_phone` null (allowed by #3 for a distorted r): the prompt names the error type and never prints `None`. Pinned by `test_prompt_holds_the_facts`.
4. A session with no errors: the prompt says `Errors heard: none` and the line is a pass. Pinned by `test_prompt_with_no_errors`.
5. A child just under a cutoff (6;8, gliding): the error is in the prompt as "normal for age", and the line is a pass. Pinned by `test_pass_line_with_no_model` and `test_prompt_holds_the_facts`.

Not covered, by design:
- A model that still writes "pass" or "refer" in its own text. The prompt tells it not to, and the code's line is on top, but a 135M model can ignore an instruction. #9 sees the real model's output and decides whether to trim it.
- An age passed in years (for example `7`). The line then shows `age 0;7`, so the mistake is visible on screen. #5 owns the conversion, as in #4.

- [ ] **Step 1: Write the failing tests in `tests/test_summary.py`**

The fixture session is five tries. At 90 months (7;6) gliding flags (from 84) and distortion does not (from 96). At 80 months (6;8) neither flags.

```python
import unittest

from speakup.result import Result
from speakup.summary import build_prompt, pass_or_refer, summarize


def _try(word, error_type=None, heard_phone="ɹ"):
    return Result(word=word, target_sound="r", expected_phone="ɹ", heard_phone=heard_phone,
                  error_type=error_type, confidence=0.9, model="fake",
                  recorded_at="2026-11-05T10:15:00-06:00")


SESSION = [
    _try("rabbit", "gliding", "w"),
    _try("carrot"),
    _try("red", "distortion", None),
    _try("tree"),
    _try("mirror", "gliding", "w"),
]


class FakeModel:
    def __init__(self, reply):
        self.reply = reply
        self.prompts = []

    def __call__(self, prompt):
        self.prompts.append(prompt)
        return self.reply
```

Tests, in class `SummaryTest(unittest.TestCase)`:

- `test_prompt_holds_the_facts`: `p = build_prompt(SESSION, 90)`.
  - `assertIn("7;6", p)`
  - `assertIn("Words tried: rabbit, carrot, red, tree, mirror", p)`
  - `assertIn("rabbit: gliding (heard w), flagged for age", p)`
  - `assertIn("red: distortion, normal for age", p)`
  - `assertIn("mirror: gliding (heard w), flagged for age", p)`
  - `assertNotIn("None", p)`
  - `assertNotIn("carrot:", p)` (a correct word is not listed as an error)
- `test_prompt_with_no_errors`: `p = build_prompt([_try("carrot"), _try("tree")], 90)`; `assertIn("Errors heard: none", p)`; and `pass_or_refer` of the same list at 90 `== "Pass: 0 of 2 words flagged for age 7;6."`
- `test_refer_line_with_no_model`: `pass_or_refer(SESSION, 90) == "Refer: 2 of 5 words flagged for age 7;6 (rabbit, mirror)."`
- `test_pass_line_with_no_model`: `pass_or_refer(SESSION, 80) == "Pass: 0 of 5 words flagged for age 6;8."`
- `test_code_line_comes_first_whatever_the_model_says`: `model = FakeModel("  The child said most words well. Pass.\n")`; `summarize(SESSION, 90, model) == "Refer: 2 of 5 words flagged for age 7;6 (rabbit, mirror).\nThe child said most words well. Pass."`; and `model.prompts == [build_prompt(SESSION, 90)]` (one call, with the facts prompt).
- `test_empty_session_raises_before_the_model`: `model = FakeModel("x")`; `assertRaises(ValueError)` on `summarize([], 90, model)`; then `model.prompts == []`.

- [ ] **Step 3: Write `speakup/summary.py`**

- `Generate = Callable[[str], str]` at module level.
- Age text is `f"{age_months // 12};{age_months % 12}"`.
- `pass_or_refer`: raise `ValueError` when `results` is empty. Otherwise collect the flagged words in session order with `should_flag`, and return the exact copy from decision 2: `Pass: 0 of {n} words flagged for age {age}.` when none is flagged, else `Refer: {k} of {n} words flagged for age {age} ({w1, w2}).`
- `build_prompt`: raise `ValueError` when `results` is empty. Return exactly this shape (one error line per try with an error, in session order; `(heard X)` only when `heard_phone` is not null; `flagged for age` or `normal for age` from `should_flag`; `Errors heard: none` with no error lines when there are no errors):

```
Write 2 or 3 short, plain sentences for a school speech therapist about one speech screening session.
Use only the facts below. Do not say whether the child passes or should be referred. Do not diagnose.

Child's age: 7;6
Words tried: rabbit, carrot, red, tree, mirror
Errors heard:
- rabbit: gliding (heard w), flagged for age
- red: distortion, normal for age
- mirror: gliding (heard w), flagged for age
```

- `summarize`: compute `pass_or_refer` first (so an empty session raises before the model runs), call `generate(build_prompt(...))` once, and return `f"{line}\n{reply.strip()}"`.
- A short module docstring in the style of `speakup/result.py`, naming #7 and that `generate` is the seam #9 points at llama.cpp.
