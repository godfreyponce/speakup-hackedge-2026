# PERCEPT-R test set (issue #14) Implementation Plan

> **For agentic workers:** Build with `/build-ticket 14`. This is a single-task plan: the work stays uncommitted in the working tree for gate 2. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standard-library script that reads the PERCEPT-R zip in place and writes a fixed, repeatable list of 300 listener-rated child clips (start-r and end-r, correct and wrong) plus the IDs of the speakers #2 must keep out of training.

**Architecture:** One script, `scripts/pick_test_set.py`, with no imports from the repo (it runs under `python3 -I`, which keeps the script's folder off `sys.path`). It indexes the zip's member names, reads each child's age pickle and each candidate label pickle with `pickletools.genops` (never `pickle.load`), walks the child speakers in a seeded order until all four cells can be filled, and writes two files beside the zip. A counts doc records the real run.

**Tech Stack:** Python 3, standard library only (`zipfile`, `pickletools`, `io`, `csv`, `random`, `argparse`, `unittest`).

**Spec:** GitHub issue #14 ("Test set from PERCEPT-R: 300 start-r and end-r clips, held out by speaker"), all six "Decisions to confirm" as written there, plus the owner's run note quoted in Global Constraints. Consumer: #2.

## Decisions taken in this plan (gate 1)

1. **How many speakers are held out: walk the children in seeded order and stop as soon as every cell can be filled.** The ticket says "picks test speakers first" but names no count. A dry run on the real corpus with this rule and seed 2026 holds out **55 of 173 child speakers, which removes 21,639 of 105,647 clips (about 20%) from #2's training pool**. Other seeds gave 56 to 66 speakers and 21k to 33k clips. The cell that sets the size is end-r / correct: only 97 child speakers have any clear-correct end-r clip, and one clip per speaker per word allows about 3 per speaker. If 20% is too much for #2, the cheaper levers are a smaller set (decision 1 on the ticket) or more end-r words, not a different walk.
2. **The two output files go in the zip's folder, not the current directory.** `python3 -I scripts/pick_test_set.py data/percept-r/PERCEPT-R.zip` writes `data/percept-r/test-set.csv` as the ticket says, and the build's run with the absolute path writes into the main checkout's `data/percept-r/`, so no label ever lands in the worktree. There is no `--out` flag.
3. **One clip per (speaker, word) is chosen at random before it is sorted into a cell.** Of that pair's clear clips (sorted by member path), `rng.choice` picks one, and its label decides the cell. This makes "at most one clip per speaker per word" hold by construction and avoids always taking take 1.
4. **Seed 2026.** Arbitrary; any fixed int works. It is a constant, `SEED`.
5. **Word lists, final:** start = `rabbit, rain, ring, rocket` (the start words in `speakup/words.csv`; all four are in the corpus, rabbit has 134 child clips) + `red, rock, run, rug, rose`. End = `car, door, bear` (the end words in `words.csv`; all in the corpus) + `star, chair, floor, hair, pear, deer`. `ring` is listed once. The script does not read `words.csv`: decision 6 wants the lists explicit, and `-I` cannot import `speakup` anyway.
6. **What counts as "one float" and "an int".** The opcodes `PROTO`, `FRAME`, and `STOP` are framing and are ignored; what remains must be exactly one `BINFLOAT` for a label, or exactly one `BININT1`/`BININT2`/`BININT` for an age. Anything else (a string such as `'NA'`, `MEMOIZE`, a list, an object, bytes that `genops` cannot parse) returns `None`. The real corpus has two shapes for labels (105,476 float, 171 `'NA'` string) and two for ages (279 `BININT1`, 1 `BININT2`, the 288-month speaker), all handled.
7. **The skipped-label count covers only the labels the script reads** (child speakers, list words): 13 on the real corpus, not the corpus-wide 171. A speaker whose age pickle is not one int is skipped and counted separately (0 on the real corpus).

## Review Focus

1. A label pickle that would run code if loaded: it is skipped and counted, and the code never runs. Pinned by `test_bad_labels_are_skipped_counted_and_never_loaded`.
2. A speaker exactly 144 months old is in; 145 is out; a 288-month age stored as `BININT2` reads correctly. Pinned by `test_read_int` and `test_age_filter_and_word_lists`.
3. A label of exactly 0.25 or 0.75: wrong and correct respectively; 0.26 and 0.74 are out. Pinned by `test_label_rule`.
4. A corpus copy that cannot fill a cell (a different version on Raf's machine): the script stops with a message naming the short cell and writes no file. Pinned by `test_not_enough_clips_raises`.
5. One speaker with two takes of the same word, one clear-wrong and one clear-correct: at most one of them is in the set. Pinned by `test_hold_out_and_one_clip_per_speaker_word`.

Not covered, by design:
- One word filling most of a cell (chair has 1,363 child clips). The ticket sets no per-word balance; the doc's table is per cell only. Lexi's word-list review is the place to raise it.
- The same output on another Python 3 version. `random.Random(int)`, `shuffle`, `choice`, and `sample` have been stable across CPython 3.x, but the real cross-check is Raf running the script on his copy and comparing bytes.

  - `write_outputs(picked: Picked, out_dir: str) -> None` — writes `test-set.csv` and `test-speakers.txt` in `out_dir`.
  - `main(argv: list[str] | None = None) -> int`

- [ ] **Step 1: Write the failing tests in `tests/test_pick_test_set.py`**

The fixture, built once per test in a `tempfile.TemporaryDirectory`:

`_Trip` is a test-module class whose `__reduce__` returns `(_trip, ())`, and `_trip()` appends to a module-level list `TRIPPED`. Loading that pickle would call `_trip`; reading it with `genops` does not.

With `per_cell=2` the children (1 to 4) can fill every cell; each end cell has exactly 4 candidates, so `per_cell=5` cannot.

Tests, in class `PickTestSetTest(unittest.TestCase)`:

- `test_read_float_accepts_one_float_only`: `read_float(pickle.dumps(0.111, protocol=4)) == 0.111`; `None` for `pickle.dumps("NA")`, `pickle.dumps([0.5])`, `pickle.dumps(1)`, `b"not a pickle"`, and `pickle.dumps(_Trip())`; then `TRIPPED == []`.
- `test_read_int`: `read_int(pickle.dumps(110, protocol=4)) == 110`; `read_int(pickle.dumps(288, protocol=4)) == 288`; `read_int(pickle.dumps(0.5)) is None`; `read_int(pickle.dumps("ten")) is None`.
- `test_label_rule`: `listener_says` gives `"wrong"` for 0.0 and 0.25, `"correct"` for 0.75 and 1.0, `None` for 0.26, 0.5, 0.74.
- `test_counts_per_cell`: `p = pick(zip, per_cell=2)`; the `Counter` of `(position, listener_says)` over `p.rows` equals `{cell: 2 for cell in CELLS}`; `len(p.rows) == 8`.
- `test_age_filter_and_word_lists`: for `p = pick(zip, per_cell=2)`: no row has speaker `"5"` or `"6"`, and neither is in `p.test_speakers`; every row's word is in `START_WORDS` with position `"start"` or in `END_WORDS` with position `"end"`; no row's word is `cheer`, `rah`, or `pear`; `p.children == 4` (speakers 1 to 4, so 144 is in); `p.skipped_speakers == 1`; every row's `age_months` matches the table.
- `test_hold_out_and_one_clip_per_speaker_word`: every row's speaker is in `p.test_speakers`; `(speaker, word)` pairs over `p.rows` are unique; `p.clips_total == 27` (every `.wav` in the fixture); `p.clips_removed` equals the number of fixture `.wav` members whose speaker is in `p.test_speakers` (counted in the test from the fixture table, which includes `cheer` and `rah`).

- [ ] **Step 3: Write `scripts/pick_test_set.py`**

- `read_float` / `read_int`: `ops = [(op.name, arg) for op, arg, _ in pickletools.genops(io.BytesIO(data)) if op.name not in ("PROTO", "FRAME", "STOP")]`, catching `ValueError` as `None` (that is what `genops` raises on unknown opcodes, truncated data, and a missing `STOP`; checked on junk bytes while planning). Accept only `len(ops) == 1` with name `BINFLOAT`, or `BININT1`/`BININT2`/`BININT` for ints (decision 6).
- Member paths have the shape `<root>/<speaker>/<kind>/<file>`; do not hard-code the root name. A clip is a `.wav` under `audio/`; its label is `<root>/<speaker>/rhotic_perceptual_labels/<stem>.pickle`. Stems split on `_` into 5 fields with the word at index 3; ignore stems that do not.
- `pick`, in this order (the order fixes the output, so keep it):
  1. Index the zip's names once. `clips_total` = count of `.wav` members.
  2. For each speaker folder, read `metadata/age.pickle` with `read_int`; `None` → `skipped_speakers += 1`. Children are speakers with age ≤ `MAX_AGE_MONTHS`.
  3. For each child, for each clip whose word is in `START_WORDS + END_WORDS`, read its label with `read_float`; `None` → `skipped_labels += 1`; keep it only if `listener_says` is not `None`. Group the kept clips by `(speaker, word)`.
  4. `rng = random.Random(seed)`; `order = sorted(children, key=int)`; `rng.shuffle(order)`.
  5. Walk `order`. For each speaker: for each of its words in alphabetical order, `rng.choice` one clip from that pair's kept clips sorted by `zip_path` (decision 3) and append it to `pool[(position, says)]`; then add the speaker to the held-out list. Stop after the first speaker at which every cell in `CELLS` has `>= per_cell` clips.
  6. If the walk ends first, raise `ValueError` listing each short cell as `"<position> <says>: <have> of <per_cell>"`.
  7. For each cell in `CELLS` order, `rng.sample(pool[cell], per_cell)`.
  8. `rows` sorted by `(CELLS.index((position, says)), zip_path)`; `test_speakers` = held-out list sorted by `int`; `clips_removed` = `.wav` members whose speaker is held out.
- `write_outputs`: `csv.writer` with `lineterminator="\n"`, file opened with `newline="", encoding="utf-8"`; header `COLUMNS`, then the rows (the label is written as the float, so its full repr). `test-speakers.txt`: one ID per line, ending in a newline.
- `main`: one positional argument, the zip path. Call `pick`; on `ValueError` print the message to stderr and return 1, having written nothing. Otherwise call `write_outputs(picked, os.path.dirname(os.path.abspath(zip_path)))` (decision 2) and print exactly these lines, then return 0:

```
test speakers: <n> of <children> children, ages <min>-<max> months
clips picked: start correct 75, start wrong 75, end correct 75, end wrong 75
label pickles skipped (not one float): <skipped_labels>
speakers skipped (age not one int): <skipped_speakers>
training pool: <clips_total> clips, <clips_removed> removed by the speaker hold-out, <clips_total - clips_removed> left
wrote <csv path> and <txt path>
```

  The age range is over the held-out speakers. The cell counts come from the rows, not from `PER_CELL`.
- `if __name__ == "__main__": sys.exit(main())`. A short module docstring naming #14, #2 as the consumer, the run command, and the citation.
