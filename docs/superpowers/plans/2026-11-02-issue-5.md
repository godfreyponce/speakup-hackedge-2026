# App skeleton: session flow with the fake model (issue #5) Implementation Plan

> **For agentic workers:** Build with `/build-ticket 5`. This is a multi-task plan: build on the ticket branch `issue-5`, one commit per approved task. **Task 1 ends with a stop for the owner to pick a mockup**; the build resumes on the owner's reply. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A therapist runs a whole screening session in a browser, served by the board (or a laptop), with the fake model: start with child ID and age, say each practice word, see what was heard and whether it is flagged, and end on a tally with a pass or refer line.

**Architecture:** Standard library only. `speakup/session.py` holds the session state and the rules (input checks, the #4 age rule, tally, pass or refer) with no I/O. `speakup/recorder.py` records a clip: a fake that does nothing on a laptop, and `arecord` on the board. `speakup/server.py` is an `http.server` app that renders plain HTML forms from `speakup/pages.py`, with no JavaScript and nothing loaded from off the board. `python3 -m speakup` starts it. Task 5 adds a scripted demo model behind `--demo`.

**Tech Stack:** Python 3 (3.14 on the dev laptop; the board version is still unknown, see #1), standard library only: `http.server`, `html`, `urllib.parse`, `subprocess`, `argparse`, `unittest`.

**Spec:** GitHub issue #5 ("App skeleton on the board: session flow with the fake model"). It uses #3's result format (`docs/result-format.md`, `speakup/result.py`, `speakup/fake_model.py`), #4's age rule (`speakup/age_norms.py`, `should_flag` takes age in **months**), and #10's word list (`speakup/words.csv` through `speakup/words.py` `load_words()`). All three are merged on main.

## Global Constraints

- Runs on the board in Python 3. #1 has not reported whether `pip` works, so: standard library only.
- "The mic is on the board, not in the browser." The Record button asks the server to run `arecord` on the board. On a laptop, the recorder is faked.
- "No internet calls, no CDN links. Everything the page loads comes from the board." No JavaScript, no external CSS, fonts, or images: each page is one HTML document with inline CSS.
- "No audio or child data in the repo." Clips go to `recordings/`, which `.gitignore` already blocks. Tests use made-up IDs (`S-014`) and temp folders.
- Words come from `load_words()`; nothing in #5 hard-codes the word list (#10: "the swap touches nothing else").
- Flags come from `should_flag(result.error_type, result.target_sound, age_months)`; every model output goes through `check()` first.
- `arecord` records 16 kHz mono WAV, the format #1's done-when names.

## Decisions taken in this plan (gate 1)

1. **Open question 1, a scripted demo mode: included, as its own task (Task 5).** `python3 -m speakup --demo` swaps the random fake for a script keyed by word (for example rabbit is always heard as gliding). The presenter says "wabbit" and the screen agrees. If a word in `words.csv` has no line in the script, the server refuses to start, so the gap shows before the demo, not during it. The default stays the random fake. Alternatives: (b) `--seed N` makes the random fake repeat the same run, which is one flag but breaks the moment a word is recorded twice; (c) leave it to #11. Task 5 can be dropped at gate 1 without touching Tasks 1–4.
2. **Open question 2, the end-r words (car, door, bear): kept as they are in #5.** The app passes each word through, and `expected_phone` stays `"ɹ"` as #3's format says. Whether end-position r is a separate target (with its own expected phone, error types, and age norms) is Lexi's call on #10 and #2's call for the model; the owner adds it as a comment on #10. Alternative: the session skips `position == "end"` words until that is settled (one filter line in `__main__`).
3. **Standard library only.** It works whether or not `pip` works on the board.
4. **Server-rendered HTML forms, not a JSON API with a JavaScript page.** Each step is a page and each button is a form `POST` that redirects (303) to the next page. Tests can read the HTML directly, and the page cannot load anything from off the board by accident. Record blocks for the clip length, then the page shows the result.
5. **Age is entered as years and months**, stored as `age_months`, shown as `7;4` (SLP notation). Years alone would lose up to 11 months at the 84-month gliding cutoff. Months may be left blank (counts as 0).
6. **Child ID: letters, digits and hyphens only** (`S-014`). Code cannot tell a name from an ID, so the form says "no names". The character rule is there because the ID goes into the clip's file name: a `/` or `..` must never reach a path.
7. **Pass or refer: "refer" when at least one word is flagged.** No source gives a higher count, so the plan does not invent one. This is for Lexi to confirm. #7 also needs this line ("comes from the code"); it lives in one function, `pass_or_refer`, so #7 calls it instead of writing a second one.
8. **Clips are kept** in `recordings/` as `<child_id>-<YYYYmmddTHHMMSS>-<word>.wav`, so the board check can play one back. #6 decides how long they stay.
9. **Recorder flags.** Default: the fake recorder. On the board: `--arecord`, plus `--device` (passed as `arecord -D`, because the board's default capture device may be its onboard codec, not the USB mic) and `--seconds`, default `3`. **The 3 is a guess**; tune it on the board.
10. **Next word only after a result; Record again is allowed.** Recording again replaces the current word's result. A word with no result cannot be skipped.
11. **Visual rule.** `AGENTS.md`'s `# Visual rule` says **3** single-file HTML variants (the global command says 4; the repo section wins). Its folder and keep-or-delete fields are still template placeholders, so this plan picks: the variants go in `mockups/issue-5/`, the winner's layout and CSS are wired into `speakup/pages.py`, and the two losing files are deleted before the Task 1 commit. **References, for the owner to confirm or replace at gate 1:** (a) a flashcard app's study mode, such as Quizlet's, with one big word per screen; (b) the Goldman-Fristoe (GFTA-3) record form that SLPs already fill in, a grid of words with a mark per sound; (c) a screening form Lexi uses, if she has one. No variant is built before the owner confirms the references.
12. **The board done-when box cannot be checked tonight** (the SD card is being re-flashed, #1). The build tests `arecord` with a stub command. At accept, if the board is still not up, the proposal is to close #5 and open one small ticket, "Check #5's Record on the board", blocked on #1. The alternative is to keep #5 open until the board check passes.
13. **One request at a time** (`http.server.HTTPServer`, not the threading server). There is one therapist, and the session needs no locks. While a clip records, other requests wait.

## Review Focus

1. **The mic fails** (unplugged, wrong `--device`): the word page shows "Recording failed: <arecord's message>", the session stays on the same word, and Record works again. Pinned by `test_recorder_error_shows_on_word_page` (Task 4) and `test_arecord_failure_raises_with_stderr` (Task 3).
2. **The model returns a bad record**: `check()` raises, and the page shows the error. The server does not crash and stores nothing. Pinned by `test_bad_model_record_shows_error` (Task 4).
3. **A child ID with a slash, a space, or `..`**: 400, the start form again, no session. Pinned by `test_parse_child_id` (Task 2) and `test_start_rejects_bad_input` (Task 4).
4. **Age at the gliding cutoff entered as years and months**: 6 years 11 months does not flag; 7 years 0 months flags. Pinned by `test_flag_uses_age_rule` (Task 2) and `test_record_shows_flag_for_age` (Task 4).
5. **Pages reached out of order** (a bookmark, the Back button, a refresh): `/word` or `/summary` before Start redirects to `/`; `POST /next` before a result stays on the word. Pinned by `test_pages_before_start_redirect_home` and `test_next_waits_for_a_result` (Task 4).

Not covered, by design: an `arecord` that hangs (no timeout; no source gives a safe number, and `-d` ends the clip on its own); a real name typed as an ID (the form text guards it, not code); two browsers using the server at once (one session; a new Start replaces it).

### Task 2: Session state and rules

**Files:**
- Create: `speakup/session.py`
- Test: `tests/test_session.py`

**Interfaces:**
- Consumes: `Word` and `load_words` (`speakup/words.py`); `Result` and `ERROR_TYPES` (`speakup/result.py`); `should_flag` (`speakup/age_norms.py`).
- Produces:
  - `parse_child_id(raw: str) -> str`: strips whitespace, then requires a full match of `[A-Za-z0-9-]+`, else `ValueError`.
  - `parse_age(years: str, months: str) -> int`: returns age in months. `years` is a required integer `>= 0`. `months` is blank (0) or an integer from 0 to 11. Anything else raises `ValueError`.
  - `format_age(age_months: int) -> str`: `88 -> "7;4"`.
  - `@dataclass(frozen=True) class Attempt: word: Word; result: Result; flagged: bool`
  - `class Session(child_id: str, age_months: int, words: list[Word])` with:
    - `current_word -> Word | None` (None when done)
    - `current_attempt -> Attempt | None` (the result for the current word, if recorded)
    - `add_result(result: Result) -> Attempt` (sets or replaces the current word's attempt; `flagged = should_flag(result.error_type, result.target_sound, self.age_months)`)
    - `next() -> None` (moves on only if the current word has an attempt; otherwise does nothing)
    - `done -> bool`
    - `attempts -> list[Attempt]` (one per finished or current word, in order)
  - `tally(attempts: list[Attempt]) -> dict[str, int]`: flagged count per error type, with a key for every type in `ERROR_TYPES` (`{"gliding": 1, "distortion": 0}`).
  - `pass_or_refer(attempts: list[Attempt]) -> str`: `"refer"` if any attempt is flagged, else `"pass"`.

### Task 4: Server, pages, and `python3 -m speakup`

**Files:**
- Create: `speakup/pages.py`, `speakup/server.py`, `speakup/__main__.py`
- Modify: `README.md` (add a "Run the app" section after "Work")
- Test: `tests/test_server.py`

**Interfaces:**
- Consumes: everything from Task 2 and Task 3; `check` from `speakup/result.py`; `fake_listen` from `speakup/fake_model.py`; the winning mockup from Task 1.
- Produces:
  - `Listen = Callable[[str, Path], dict]`: a model takes the word and the clip path, and returns a #3 record as a dict.
  - `make_server(host: str, port: int, *, words: list[Word], listen: Listen, recorder, recordings_dir: Path) -> http.server.HTTPServer`. The server holds one `Session | None`.
  - Routes:

| route | does | answer |
|---|---|---|
| `GET /` | start form: child ID ("letters, digits, hyphens; no names"), age years, age months | 200 |
| `POST /start` | `parse_child_id`, `parse_age`; a new `Session(words)` replaces any old one | 303 to `/word`; 400 with the start form and the error |
| `GET /word` | the current word large; Record. With a result: what was heard, the flag line, Record again, Next word. Footer: `model: <result.model>` once a result exists | 200; 303 to `/` with no session; 303 to `/summary` when done |
| `POST /record` | `recorder.record(path)`, then `check(listen(word, path))`, then `session.add_result` | 303 to `/word`; 500 with the word page and the error on `RecorderError` or `ValueError`; 303 to `/` with no session |
| `POST /next` | `session.next()` | 303 to `/summary` when done, else to `/word`; 303 to `/` with no session |
| `GET /summary` | one row per word (word, heard, flagged); `Flagged: gliding N, distortion N`; the pass or refer line | 200; 303 to `/` with no session |
| anything else | | 404 |

  - Clip path: `recordings_dir / f"{child_id}-{datetime.now():%Y%m%dT%H%M%S}-{word}.wav"`.
  - Copy, exact (tests match on it):
    - heard: `Heard: {heard_phone or "not named"} ({error_type or "correct"})`
    - flag line, only when `error_type` is set: `Flagged for age {format_age}` or `Normal for age {format_age}`
    - error: `Recording failed: {message}` for `RecorderError`, `Model gave a bad result: {message}` for `ValueError`
    - pass: `Pass: no words flagged for age {age}.`
    - refer: `Refer: {n} of {total} words flagged for age {age}. The therapist decides on a full assessment.`
  - Every value put into HTML goes through `html.escape`. Read form bodies with `urllib.parse.parse_qs` on `Content-Length` bytes, as UTF-8.
  - `python3 -m speakup [--host 0.0.0.0] [--port 8000] [--arecord] [--device D] [--seconds 3]`: `words = load_words()`, `listen = lambda word, path: fake_listen(word)`, `recordings_dir = Path("recordings")`, recorder `ArecordRecorder(seconds, device)` with `--arecord`, else `FakeRecorder()`. Print `Speak Up on http://<host>:<port>`, then `serve_forever()` until Ctrl-C.
