## The planner's finding: a source for BY-ND turned up

The ticket says no source for BY-ND was found on Nov 4. The ticket read web pages only. The corpus copy the team trains on has one. `PERCEPT-R.zip` (main folder, `data/percept-r/`) holds exactly one text file, `PERCEPT-R 2.2.2py/README.txt` (213,255 entries: 106,487 `.pickle`, 105,647 `.wav`, 1,120 folders, 1 `.txt`). Its second paragraph, read on Nov 10, 2026 with Python's `zipfile`:

> This is the Python-ready version of PERCEPT-R version 2.2.2.
> PERCEPT-R 2.2.2py is licensed under a Creative Commons Attribution-NoDerivatives 4.0 International License (CC BY-ND 4.0). https://creativecommons.org/licenses/by-nd/4.0/

The ticket's first Done-when item covers this case: "unless a source for BY-ND turns up; if one does, link it instead." So this plan keeps BY-ND for the 2.2.2py copy and names its source. It also states TalkBank's CC BY-NC-SA 4.0 default and its media rule, because those pages are real and apply to TalkBank data. It says the conflict between the two is open. (Decision 1.)

Sources checked by the planner on Nov 10, 2026 (all quotes below are from these reads):

- TalkBank Ground Rules, https://talkbank.org/0share/rules.html: "Except where otherwise indicated, the use of TalkBank data is governed by the Creative Commons CC BY-NC-SA 4.0 copyright license." "TalkBank media materials cannot be redistributed on the web without case-by-case permission from the corpus contributor." "Materials can be used locally for instructional purposes if access is closely controlled." The page says nothing on derived works; it names models only in "the data themselves cannot be included in models" (about commercial enterprises).
- PERCEPT-R corpus page, https://talkbank.org/phon/access/Clinical/PERCEPT-R.html: no license statement. "any use of data from this corpus must be accompanied by at least one of the above references." The first reference is the 2022 Interspeech paper.
- Contributor permission form, https://talkbank.org/phon/permissions/Clinical/PERCEPT-R.pdf (Nina R Benway, Syracuse University, 8 March 2024): "2. Restrictions to be placed on the use of the data: None."
- Benway et al. 2023, https://pmc.ncbi.nlm.nih.gov/articles/PMC12510240/: "The PERCEPT project is distributed for noncommercial use through PhonBank". The article names no license. It calls the Python-ready version planned ("We also plan to release a derived version of the corpora").
- Benway et al. 2022: Benway, N. R., Preston, J. L., Hitchcock, E. R., Salekin, A., Sharma, H., & McAllister, T. "PERCEPT-R: An Open-Access American English Child/Clinical Speech Corpus Specialized for the Audio Classification of /ɹ/." Proc. Interspeech 2022, pp. 3648-3652. doi:10.21437/Interspeech.2022-10785 (ISCA archive page and the 2023 article's reference list agree). Its page states no license.

## Decisions taken in this plan (gate 1)

1. **Keep BY-ND, now with its source, and add TalkBank's terms beside it.** The ticket expected NC-SA. The README inside the 2.2.2py release says BY-ND, and the ticket's own Done-when says to link a BY-ND source if one turns up. The docs therefore say: this release says BY-ND; TalkBank's default is BY-NC-SA "except where otherwise indicated"; Benway 2023 says noncommercial through PhonBank; which terms govern this copy is open. If the owner wants the docs to lead with NC-SA anyway, say so at gate 1.
2. **One `## License` section, in `docs/test-set.md`.** That file is the corpus doc and already holds the citation. `docs/model-timing.md` names the terms in one sentence and links to `test-set.md#license`, so the quotes live in one place.
3. **The reason for not committing changes.** BY-ND lets anyone share unchanged copies with credit, so "the corpus is CC BY-ND" was never the reason clips stay out of git. The new reasons: TalkBank distributes the corpus, and its media "cannot be redistributed on the web without case-by-case permission"; the repo's own rule (`README.md` line 40) is "Never commit audio recordings or any child data"; and files made from the corpus (the test list, the mel cache, a trained model) may be adapted material, which BY-ND does not let anyone share and BY-NC-SA lets anyone share only noncommercially under the same license. Whether they are adapted material is open.
4. **"No model file is in git." stays as it is in `docs/model-timing.md`.** It is false today: `ff0968c` tracks `models/arti-v0.onnx` and `.gitignore` un-ignores it. #25 owns making it true again ("`docs/model-timing.md` says no model file is in git; make that true again"). This plan does not touch that sentence or `.gitignore`.
5. **What the `grep -rn "BY-ND"` check finds, and what happens to each hit** (Done-when 3):
   - `docs/test-set.md:57`, `docs/model-timing.md:87`: rewritten (Task 1).
   - `scripts/train_arti.py:14`, `scripts/pick_test_set.py:12` (module docstrings, "CC BY-ND 4.0."): left as they are. They now agree with the README source, and the ticket says no code change.
   - `docs/superpowers/plans/2026-11-03-issue-2.md:18`, `docs/superpowers/plans/2026-11-03-issue-14.md:155`: left as they are. Plan files are records of what was planned on that day.
   - Issue #25's title says "(PERCEPT-R is CC BY-ND)". It matches the README; no change.
6. **The hackedge repo's demo Q&A line is not in this repo.** The ticket says it "is fixed separately". If that fix changed it to NC-SA, it now disagrees with the README. That is an owner check outside this build.
